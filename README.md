# Jelajah Bahasa Melayu Tahun 4

Permainan interaktif digital untuk Bahasa Melayu Tahun 4.

## Kandungan
- Nota infografik
- 25 soalan
- 3 tahap
- Sistem bintang
- Ruang nama murid
- Bunyi betul/salah
- Suara Bahasa Melayu melalui SpeechSynthesis peranti
- Responsif untuk telefon/tablet
- Boleh dihoskan sebagai GitHub Pages

## Maklumat PdP
Guru: MUHAMAD SYAWALWAHED
Sekolah: SK (P) JALAN YAHYA AWAL
Fokus: Kemahiran Mendengar dan Bertutur
SK 1.1: Mendengar dan memberikan respons semasa berkomunikasi dalam situasi formal dan tidak formal.
SP 1.1.1–1.1.3: sebutan/ujaran semula, memahami dan memberi respons terhadap ujaran, serta mentafsir dan memberi respons terhadap soalan secara kritis.

## Cara guna
1. Buka `index.html`.
2. Masukkan nama murid.
3. Tekan Mula.
4. Untuk GitHub Pages: buat repository baharu, muat naik `index.html` dan aktifkan Settings > Pages > Deploy from branch > main/root.
